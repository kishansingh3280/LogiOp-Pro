# Install LogiOp Pro on Android (beginner)

## Download the APK

Get **LogiOp-Pro.apk** from the pull request artifacts / download link shared by your developer.

## Install on your phone

1. Copy the APK to your phone (Download folder).
2. Open the file with **Files** or **Chrome**.
3. Allow **Install unknown apps** when Android asks.
4. Tap **Install** → **Open**.

## First open

- **Demo mode is ON** by default.
- You will see sample customers, ledger balances, and a 25-bag shipment.
- No computer or internet server is required to explore.

## Later: connect to your real data

1. Run the web app on your computer (`npm run dev`).
2. In the phone app go to **Settings** (gear icon).
3. Turn **Demo mode** OFF.
4. Enter your computer’s IP, e.g. `http://192.168.1.10:3000`.
5. Tap **Save & connect to server**.
